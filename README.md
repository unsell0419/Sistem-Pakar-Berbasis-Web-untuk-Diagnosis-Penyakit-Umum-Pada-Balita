# Sistem-Pakar-Berbasis-Web-untuk-Diagnosis-Penyakit-Umum-Pada-Balita
Aplikasi Sistem Pakar berbasis Web yang dirancang untuk membantu deteksi dini penyakit umum pada balita secara cepat dan responsif. Sistem ini membantu orang tua mengenali gejala awal sebelum melakukan pemeriksaan medis resmi, serta menjadi sarana mitigasi keterbatasan akses ke fasilitas kesehatan.
